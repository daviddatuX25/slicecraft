### II. Application

Create a dynamic and database-driven shopping website for the admin view. The website must consist of the following modules or processes using the **Laravel PHP Framework**. **(60 points)**

#### Site Hierarchy / System Architecture Diagram

```text
Shopping Website (Admin View)
│
├── Login
│
├── Manage Product
│   ├── Search / View Product
│   ├── Add Product
│   ├── Update Product
│   └── Delete Product
│
├── Manage Customer
│   ├── View Customer
│   └── Update Customer Status
│
└── Manage Cart or Order
    ├── View Cart Products
    └── Delete Cart Products
```
