Generate these base references before generating the 20 combinations. The base references establish consistent cake identity, frosting texture, camera angle, background, and scale.

Use `00-style-bible.md` for every prompt. Save outputs exactly as listed.

**Input reference:** `../source-inspiration/cake2go-classic-cakes/classic-ube-reference.png`

**Output:** `base-references/classic-ube-base.png`

**Prompt:**

Create an original premium bakery product photograph of a whole Classic Ube cake for a fictional bakery called SliceCraft. Use the attached Classic Ube reference only for broad flavor inspiration, not for copying its exact composition. Show a soft purple ube sponge or ube-flavored cake with smooth pale lavender cream, restrained ube crumbs, and a clean elegant finish. Use a warm cream studio background, three-quarter front view, soft diffused bakery lighting, realistic frosting texture, a subtle contact shadow, and a 4:5 portrait composition. One cake only, no text, no logo, no packaging, no people, no watermark.
