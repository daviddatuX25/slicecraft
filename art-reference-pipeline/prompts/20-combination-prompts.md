# Twenty Combination Generation Prompts

Generate these one at a time only after the four base references pass review. Attach the matching base reference and any available standalone additive references. Apply `../prompts/00-style-bible.md` to every prompt.

General instruction for every output: create an original SliceCraft product photograph from the attached base reference and named additive references. Preserve the base cake identity and three-quarter product-photo angle, but create a new composition. Do not copy the source image. No text, logos, packaging, people, hands, watermark, or brand marks. Save using the exact filename shown.

### Anti-Contamination & Additive Isolation Rules
When an additive reference is attached to any prompt below, you must strictly follow these isolation boundaries (see `../standalone-additives/README.md` for full specs):
- **Isolate the motif only:** Extract solely the named additive object or pattern (e.g. the fruit cluster, the chocolate drip, or the piped rosette border).
- **Prevent cake contamination:** NEVER allow the additive reference's underlying cake body, shape, background table, dishware, or frosting color to replace or bleed into the base cake. The base cake's flavor, frosting color, and geometry from `base-references/` must remain sovereign.
- **Color harmony:** Piped trims and decorations must adapt to the base cake's flavor family (e.g. lavender for Ube, cocoa for Fudge, ivory for Red Velvet and Mango).
